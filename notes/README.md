# SYZ 的笔记

记录课程内容、技术实践与个人学习总结。

## 嵌入式与机器人

* [铁头山羊 STM32 入门教程](ke-cheng-ji-lu/stm32/)：52 课忠实图文记录，包含原片时间链接。
* [FreeRTOS 源码详解](ke-cheng-ji-lu/freertos-source/)：10 集，从列表结构到队列、任务切换的源码级讲解。
* [嵌入式 AI 教程 · RK3588](ke-cheng-ji-lu/embedded-ai-rk3588/)：35 集，NPU 原理、RKNN 工具链与模型部署全流程。
* [RK3588 精品公开课](ke-cheng-ji-lu/rk3588-course/)：瑞芯微官方 7 集，NVR、RKNN 精度优化与 Runtime 部署。
* [ROS2 入门](ke-cheng-ji-lu/ros2-intro/)：ROS 命令行与基础概念整理。

## 大模型与 AI 应用

* [2025 大模型 RAG 入门](ke-cheng-ji-lu/rag-intro/)：5 集，从基本流程到优化技巧与评估方法。
* [微调：从原理到实操](ke-cheng-ji-lu/finetuning-practice/)：SFT、RLHF 概念与 Linux 上微调部署的完整流程。
* [LoRA 论文解读与微调部署](ke-cheng-ji-lu/lora-paper/)：LoRA 算法原理与对外接口暴露实践。

## 工程与运维实践

* [Linux 性能分析入门与实战](ke-cheng-ji-lu/linux-perf/)：Linux 性能观测与分析方法整理。
